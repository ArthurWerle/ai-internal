always|package-lock.json|generated lockfile. Dependency versions must not change silently; ask first.
always|pnpm-lock.yaml|generated lockfile. Dependency versions must not change silently; ask first.
always|db/drizzle/migrations/*|generated by drizzle-kit and applied at boot. Change db/drizzle/schema.ts and run `npm run db:generate` instead.
always|.agents/skills/*|vendored skill managed by skills-lock.json. Update it with the skills installer, not by hand.
always|node_modules/*|installed dependencies, never source.
